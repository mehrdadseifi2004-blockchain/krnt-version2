# KARNET 2.0 — Next.js

A bilingual (EN/FA), dark/light, minimal institutional-style landing site based on the supplied Karnet White Paper 2.0.

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- next-themes
- lucide-react
- Inter + Vazirmatn

## Notes
- Content is derived from the supplied White Paper 2.0.
- The ownership example is explicitly illustrative.
